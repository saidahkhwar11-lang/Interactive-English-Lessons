# Interactive English Lessons

Interactive English lesson webpages organized by term, grade, and lesson for classroom teaching and student learning.

## Folder structure

- `Term-1/Grade-9/`
- `Term-1/Grade-10/`
- `Term-2/Grade-9/`
- `Term-2/Grade-10/`
- `Term-3/Grade-9/`
- `Term-3/Grade-10/`
- `Lesson-Creation-Resources/` — reusable master prompt

Each lesson has its own folder containing its webpage and required assets. Editable ZIP backups are stored separately and are not uploaded to this repository.

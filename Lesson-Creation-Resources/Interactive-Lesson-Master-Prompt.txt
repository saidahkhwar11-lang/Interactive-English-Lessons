Create a NEW interactive classroom lesson webpage using the FINAL APPROVED Grade 9 “Success in College” lesson as the PRIMARY and controlling reference for layout, architecture, behavior and lesson-plan presentation.

If any older lesson, older prompt, or previous experimental behavior conflicts with the current approved Success in College lesson, FOLLOW THE CURRENT SUCCESS IN COLLEGE FORMAT.

IMPORTANT ORGANIZATION RULES
1. Every new lesson must have its own unique folder, webpage and published link.
2. Never overwrite, rename, replace or delete an existing lesson unless the user explicitly asks to update that exact lesson.
3. Keep lessons organized by Term → Grade → Lesson Title.
4. Reuse the complete working lesson architecture, not a simplified summary page.
5. The approved Success in College lesson is the GOLD-STANDARD template for future lessons.

FINAL APPROVED STABLE WRAPPER ARCHITECTURE
1. The lesson wrapper uses an iframe loading lesson-core.html.
2. The wrapper loads ONLY these approved enhancement scripts into the lesson core:
   - assets/media-persistence.js
   - assets/activity-layout.js
   - assets/lesson-plan-link.js
3. Do NOT load media-thumbnail.js.
4. Do NOT add experimental image-hide/show scripts, picture toggles, hidden-media buttons, or similar behavior.
5. Preserve the stable modular approach: lesson-core.html contains the lesson; wrapper enhancements should remain isolated and safe.
6. Prefer CSS-only/DOM-only wrapper refinements for cosmetic changes when possible. Do not change core lesson behavior unnecessarily.
7. Never publish a lesson if activity cards, refresh, or Live Lesson Plan stop working.

PERMANENT CLASSROOM DESIGN
1. Use the approved book-style lesson header, clean rounded cards and classroom-board typography.
2. Show Grade, Teacher, lesson/unit/skill, book pages and automatic UAE day/date.
3. Keep Previous, All Activities and Next navigation.
4. Keep Start, Pause and Reset timer controls for each activity.
5. Keep Full Screen/maximize support.
6. Use the established turquoise, navy, yellow, coral, white and light-grey visual system while preserving the final soft sidebar design described below.
7. Keep the interface clean, compact, attractive and uncluttered.

MAIN LESSON DASHBOARD
1. Show Objectives, Success Criteria, Key Vocabulary and Lesson Flow.
2. Show all activity cards in sequence.
3. Each card shows title, activity type, short purpose, timing and book-page metadata.
4. Normal sequence: Starter → optional Main Activities (maximum about 5) → Exit Ticket → Charter Connection Activity.

PERMANENT ACTIVITY SCREEN LAYOUT
Each launched activity uses the FINAL APPROVED Success in College layout.

LEFT / MAIN TEACHING AREA
1. On normal desktop/classroom displays, this is approximately 74% of the activity screen.
2. Put ALL questions, tasks, answer controls, revealed answers, reading paragraphs, games and Deep Thinking here.
3. Use ONE clean sequential answer-reveal control per activity wherever several questions belong to the same exercise.
4. Each click reveals the next answer beside its matching question.
5. After the final answer, the same control may switch to Hide All Answers / Reset Answers.
6. Never put activity questions, answer controls, answers, games or Deep Thinking in the right panel.
7. Rewrite textbook exercises clearly on the main area even if a textbook screenshot is also available.
8. For reading lessons, preserve readable paragraph-by-paragraph text when useful and place comprehension questions without covering the text.
9. Exit Ticket must be a complete interactive game/activity on the main area and include Restart Game.
10. Charter Connection must be a complete attractive activity on the main area using Think → Discuss → Write → Share.

RIGHT / FROZEN STUDENT GUIDE PANEL — EXACT FINAL APPROVED STYLE
1. On normal desktop/classroom displays, the entire right column is approximately 26% of the activity screen. The main area is approximately 74%.
2. At widths around 1100px and below, an approximately 70% / 30% split is acceptable.
3. At widths around 1000px and below, stack to a single-column responsive layout.
4. Keep the entire right column thin; do not merely shrink text while leaving a wide empty panel.
5. Use the exact visual direction from the approved Success in College lesson:
   - very light blue/teal guide background
   - soft gradient feel
   - white Objective card
   - pale-yellow Instructions card
   - white Lesson Step cards
   - subtle borders and shadows
   - rounded corners
   - restrained blue/teal number badges
   - compact spacing
6. Do NOT use a large dark navy Activity Guide block.
7. Include a small ACTIVITY GUIDE heading.
8. Key Words appear in a compact teal-tinted badge/card.
9. Objective is visually distinct but compact.
10. Instructions use the approved pale-yellow card with checkmark styling.
11. EVERY book-based activity must show a clearly visible Page · Activity badge inside the Instructions card, for example:
   - 📖 Page 9 · Activity 1
   - 📖 Page 9 · Activities 2–3
12. For non-book activities, use a suitable label such as “Charter Connection · Class Activity”.
13. Include a clearly separated LESSON STEPS label.
14. Lesson Steps use compact numbered white cards with slim teal accent and blue/teal number badges.
15. Keep the panel sticky/frozen and independently scrollable when needed.
16. The right panel contains ONLY:
   - Key Words
   - Activity Objective
   - Student Instructions
   - Lesson Steps / Agenda
17. Do not put questions, answers, reveal buttons, games, Deep Thinking, teacher setup controls, or teacher-only notes in this panel.

TEACHER MEDIA WORKFLOW — STABLE APPROVED VERSION
1. Every activity may have optional teacher-added media.
2. Teacher can add media by drag/drop, paste with Ctrl+V, or Browse.
3. Support one or multiple images and common audio formats such as MP3, M4A and WAV.
4. Save teacher-added media automatically with IndexedDB so it remains after refresh, closing and reopening on the same browser/device.
5. Provide Replace and Delete controls in Teacher Media Setup.
6. Teacher Media Setup must be separate from student instructions and hidden in classroom/display mode.
7. Media is optional: every activity must remain fully usable without uploaded media.
8. Preserve the current stable media-persistence behavior from the approved Success in College lesson.
9. Do NOT require or recreate the old compact-thumbnail script behavior.
10. Do NOT load media-thumbnail.js.
11. Do NOT hide textbook or teacher-added images behind a button/toggle.
12. Do NOT introduce a Show Picture / Hide Picture mechanism.
13. Audio should display as a classroom-friendly player and must not autoplay.
14. Browser-saved media is local to that browser/device; do not imply that it transfers automatically to another computer.

BOOK PICTURES / MAXIMIZED VIEW
1. Useful textbook and teacher-added images may be maximized where the approved lesson supports it.
2. Keep images clear, fitted and unobstructed.
3. Preserve working highlight / clear-marks behavior where available.
4. In maximized view controls must never cover questions or content.
5. If a textbook picture is missing or unclear, the rewritten activity content must still contain everything students need.

QUESTION / ANSWER BEHAVIOR
1. Reveal answers one by one.
2. For multi-question exercises, default to ONE sequential Reveal Next Answer button for the whole activity.
3. Each click reveals the next answer beside its own question.
4. Show a simple progress counter such as 0 / 6 revealed when useful.
5. After all answers are revealed, the same control should provide Hide All Answers / Reset Answers, or an equally simple reset control.
6. Use separate per-question answer buttons only when the activity genuinely requires independent control.
7. For vocabulary matching, shuffle choices/pictures where appropriate so answer order is not copied from the source.
8. For suitable reading/listening tasks, include one hidden Deep Thinking Challenge connected to the real lesson idea.
9. Deep Thinking stays on the main/left teaching area.

LISTENING LESSONS
1. Support teacher-added audio using the permanent saved-media workflow.
2. Include Play, Pause, Restart, progress, current/total time, volume and optional playback speed when useful.
3. Do not autoplay.
4. Use suitable stages: prediction/vocabulary → gist → details → follow-up.
5. Transcript, when useful, is hidden by default behind Reveal Transcript.
6. Listening answers reveal one by one on the main area, preferably through the same sequential reveal pattern.

EXIT TICKET
1. Make it a real interactive classroom game, not only plain written questions.
2. Use no more than about 5 core questions/clues unless the lesson genuinely needs more.
3. Answers reveal one by one on the main area.
4. Include Restart Game that resets the whole activity.
5. Teacher-added media is optional support only.

CHARTER CONNECTION
1. Keep it after Exit Ticket.
2. Infer the best axis from: Identity and Belonging; Citizenship and Responsibility; Thinking and Problem Solving; Lifelong Learning; Global Mindset and Tolerance.
3. Use Think 1 min → Discuss 2 min → Write → Share.
4. Make it visually attractive even with no uploaded picture.
5. Teacher may optionally add/replace a visual using Teacher Media.

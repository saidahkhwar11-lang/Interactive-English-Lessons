PERMANENT ACTIVITY SCREEN LAYOUT

1. On normal desktop/classroom displays, this is approximately 74% of the activity screen.
2. Put ALL questions, tasks, answer controls, revealed answers, reading paragraphs, games and Deep Thinking here.
3. Use ONE clean sequential answer-reveal control per activity wherever several questions belong to the same exercise.
4. Each click reveals the next answer beside its matching question.
5. After the final answer, the same control may switch to Hide All Answers / Reset Answers.
6. Never put activity questions, answer controls, answers, games or Deep Thinking in the right panel.
7. Rewrite textbook exercises clearly on the main area even if a textbook screenshot is also available.
8. For reading lessons, preserve readable paragraph-by-paragraph text when useful and place comprehension questions without covering the text.
9. Exit Ticket must be a complete interactive game/activity on the main area and include Restart Game.
10. Charter Connection must be a complete attractive activity on the main area using Think → Discuss → Write → Share.

QUESTION / ANSWER BEHAVIOR
1. Reveal answers one by one.
2. For multi-question exercises, default to ONE sequential Reveal Next Answer button for the whole activity.
3. Each click reveals the next answer beside its own question.
4. Show a simple progress counter such as 0 / 6 revealed when useful.
5. After all answers are revealed, the same control should provide Hide All Answers / Reset Answers, or an equally simple reset control.
6. Use separate per-question answer buttons only when the activity genuinely requires independent control.
7. For vocabulary matching, shuffle choices/pictures where appropriate so answer order is not copied from the source.
8. For suitable reading/listening tasks, include one hidden Deep Thinking Challenge connected to the real lesson idea.
9. Deep Thinking stays on the main/left teaching area.

2. Include Play, Pause, Restart, progress, current/total time, volume and optional playback speed when useful.
3. Do not autoplay.
4. Use suitable stages: prediction/vocabulary → gist → details → follow-up.
5. Transcript, when useful, is hidden by default behind Reveal Transcript.
6. Listening answers reveal one by one on the main area, preferably through the same sequential reveal pattern.
7. Never infer answers from the textbook image when audio is available. Transcribe the complete recording first and verify every answer against the exact exercise wording.
